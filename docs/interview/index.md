# 예상질문

면접 예상 질문과 답변을 정리합니다.

1. 질문 제목만 보고 답을 먼저 소리 내어 떠올립니다.
2. "답 보기"를 펼쳐 내 답과 비교합니다.
3. 헷갈렸으면 질문 제목 옆 "헷갈림"을 눌러 표시합니다. 표시한 질문은 첫 페이지에서 다시 모아 봅니다.

- [서빙·인프라·문서 처리](serving-infra.md): FastAPI, Streamlit, Docker, Kubernetes, Kibana, GitHub Actions, PDF · HTML
